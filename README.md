# MOKI 工作台 · 官方更新

此仓库用于分发 MOKI 工作台的官方安装包、更新清单及发布说明，不包含工作台应用源码，也不代表应用开源。

- [下载与版本说明](https://github.com/JKZeng-cell/moki-workbench-releases/releases)
- [MOKI 官网](https://moki.moge.tv/)

Windows 过渡版从 1.7.7 开始默认通过本仓库检查更新。较旧的 Windows 客户端可通过原更新入口升级到过渡版。

Apple Silicon Mac 当前提供原有 1.7.5 ZIP。下载位置迁移不代表应用版本升级；旧 Mac 客户端仍使用兼容清单，后续新 Mac 应用发布后再完成客户端更新源切换。

现有 Windows 安装包未签名；Mac ZIP 未签名、未公证。安装前请核对版本说明与 SHA256SUMS.txt。请勿把自动生成的 Source code ZIP 当作可安装应用。

更新清单使用固定入口，安装包使用带版本的下载地址。请勿删除仍被清单引用的资产。
